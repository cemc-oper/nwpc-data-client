# 简介

nwpc-data-client 是一个命令行工具，用于定位 CEMC 业务模式系统的输出数据文件。

核心能力：

- **路径解析**：将起报时次（`--start-time`）和预报时效（`--forecast-time`）
  应用到 YAML 配置模板，得到数据文件路径。
- **配置驱动**：数据类型按层级路径组织（如 `cma_gfs_gmf/current/grib2/orig`），
  配置可内嵌于二进制，也可由用户目录或单个文件提供。
- **文件等待**：`check local` 轮询一系列预报时效的文件，文件大小稳定后
  执行模板化命令。

核心概念：

- **数据类型（data type）**：层级相对路径，对应一个数据配置文件。
- **起报时次（start time）**：模式起报时间，格式 `YYYYMMDDHH`。
- **预报时效（forecast time）**：相对起报时间的预报时长，如 `24h`。
