# 简介

nwpc-data-client 是面向 CEMC（NWPC/CMA）业务模式系统的数据文件查找
命令行工具。它解决的核心问题是：**业务数据文件的路径随起报时次、
预报时效变化，且同一产品可能存在于多个目录**——工具用一份 YAML 配置
模板描述这些规律，按需展开并定位文件。

## 核心能力

- **路径解析**：将起报时次（`--start-time`）和预报时效
  （`--forecast-time`）应用到 YAML 配置模板，计算候选文件路径，
  返回第一个实际存在的文件（`local` 命令）。
- **配置驱动**：数据类型按层级路径组织
  （如 `cma_gfs_gmf/current/grib2/orig`）；配置内嵌于二进制，
  也可由配置目录或单个文件提供。
- **文件等待**：`check local` 命令对一组预报时效并发轮询，
  文件生成且大小稳定后执行模板化命令，适合串接后处理任务。
- **配置工具链**：`config lint` 校验、`config migrate` 在 v1/v2/v3
  格式版本间迁移、`config export` 导出内嵌配置基线。

## 核心概念

- **数据类型（data type）**：层级相对路径，唯一确定一个数据配置
  文件，详见[指南：数据类型](../guide/data-types.md)。
- **起报时次（start time）**：模式起报时间，格式 `YYYYMMDDHH`。
- **预报时效（forecast time）**：相对起报时间的预报时长，Go
  duration 格式，如 `24h`、`1h30m`。
- **位置级别（location level）**：路径条目的分级
  （`runtime` / `archive` / `storage`），控制搜索范围。
- **集合成员（member）**：集合预报的成员编号，代入模板变量
  `{{.Member}}`。

## 适用场景

- 业务调度脚本中定位某个时次、某个时效的模式产品文件；
- 等待模式产出完成后自动触发后处理、传输等下游任务；
- 在多个存储位置（运行目录 / 归档目录）之间透明查找数据。
