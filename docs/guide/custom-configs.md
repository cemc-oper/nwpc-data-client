# 使用自定义配置

三种配置来源：

1. **内嵌配置**（默认）：只给 `--data-type`，使用编译进二进制的配置。
2. **配置目录**：`--data-config-dir=<dir>` 与 `--data-type` 联用，
   加载 `<dir>/<data-type>.yaml`。
3. **单个配置文件**：`--data-config-file=<file>`，直接加载该文件，
   优先级高于前两者。

注意：

- `--data-config-dir` 是**全量替换**而非覆盖叠加：目录中缺失的配置
  会直接报错，不会回退到内嵌配置。路径中包含 `..` 逃出配置目录会被拒绝。
- 需要在内嵌配置基础上做本地扩展时，先用
  `nwpc_data_client config export <output-dir>` 导出内嵌配置基线，
  与本地新增配置合并后再分发。
