# nwpc-data-client 文档

nwpc-data-client 是面向 CEMC（NWPC/CMA）业务模式的数据文件查找工具。
它根据起报时次和预报时效展开 YAML 配置模板得到文件路径，也可以轮询等待
文件生成并执行后续命令。
